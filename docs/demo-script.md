## 评委可能提问

1. **规则准吗？会不会误报？**  
   会。它是启发式，所以命中叫“疑似问题”，每条都有误报说明与置信度；不做绝对安全承诺。

2. **会不会执行我的代码？**  
   不会。验证只有 TypeScript 静态语法解析和规则复扫，单元测试永远显示未执行。

3. **补丁安全吗？**  
   只对两种可识别形态提供模板，必须人工确认，可撤销；其他罪状只给建议，不生成假 Diff。

4. **为什么分数是 65？**  
   初始 100，极危 −25、中危 −7、低危 −3，规则确定计算；它是游戏化分数，不是安全评分。

5. **AI 在哪里？**  
   本次 Demo 刻意保持完全离线，AI 是 P1：需服务端持钥、用户同意、Zod 校验、证据回验与超时降级，不能破坏离线闭环。
